# STAR CREDIT

`shooting_game_spec.md` の段階1〜4を実装した、PCブラウザ用の縦スクロールシューティングです。HTML CanvasとJavaScript ES Modulesで構成し、依存ライブラリはありません。

## 起動

Node.js 18以上で `npm run dev` を実行し、http://localhost:5173 を開いてください。`node server.js` でも起動できます。ファイルを直接開くのではなくHTTPサーバーを利用してください。

## 操作

- 矢印キー / WASD：移動（攻撃は自動）
- Space：弾とビームの切替
- U：強化画面を開閉
- Esc：一時停止 / 再開
- メニュー：クリック、Tab / Enter、上下キー / Enter

◇を回収した時だけ残高が増加します。弾数の最初の強化は50クレジットです。180秒後、通常敵が退場してからボスが登場します。機体中心の白い点が被弾範囲です。

## 構成と調整

- `src/config.js`：敵、出現、武器性能、強化費用
- `src/model.js`：プレイ状態、回収、購入、保存復元
- `src/main.js`：時間基準の戦闘更新、描画、入力、メニュー
- `src/style.css`：画面比率を保つ表示とUI

強化・一時停止では戦闘更新を停止します。フォーカス喪失でも自動停止し、明示的な再開を待ちます。リトライはすべてのプレイ状態を作り直します。保存はバージョン付きlocalStorageでハイスコア・音量・操作確認のみを扱い、失敗時も続行できます。

## 確認

`npm test` で撃破と回収の分離、二重処理防止、強化費用・上限・性能、リトライ初期化、保存復元と破損時の既定値を検証します。

実際の戦闘更新コードをDOM・Canvasの代替環境でも実行し、弾とビームによる撃破、停止中の時間固定、被弾無敵、180秒後のボス出現、クリア時回収、同時HP0のゲームオーバー優先を含む8テストが通過しています。ブラウザ確認ツールがローカルURLを拒否したため、描画の目視確認・実際のキー操作・画面サイズ変更・通しプレイによる難易度評価は未確認です。
