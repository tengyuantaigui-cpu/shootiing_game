# 全モード追加武器・エンドレス拡張報告

## 仕様との差分と採用内容

変更前は追加装備がチャレンジ専用、エンドレスは未実装でした。モード定義の `availableWeapons` を参照して全モードに開放しました。Spaceの基本武器切替とQの追加装備切替は独立。クラシックはOFF、チャレンジ／エンドレスは拡散弾から開始します。既存敵パラメータや価格の補正は行っていません。追加装備を選ぶとクラシックの総火力が増え、従来より攻略しやすくなります。

文書内の初期提案から、通常45秒、5フェーズ周期、中央表示1.8秒を採用しました。通常フェーズは小型機中心→偵察／シールド→リーダー→砲台／特殊敵。5の倍数はボス撃破まで続きます。ボス撃破によるステージクリア、1000点ボーナス、自動回収はエンドレスにはありません。撃破報酬300のドロップを通常回収します。

難易度の暫定値はサイクル `floor((phase-1)/5)` ごとにHP+12%（最大2.5倍）、攻撃頻度+6%（最大1.6倍）、出現間隔1秒から0.035秒短縮（最短0.45秒）。既存インスタンスは変更せず、次の出現から適用します。敵の種類・速度・弾速は固定。実プレイによる最終バランス決定は残っています。

フェーズ表示は描画のみで、更新・入力・回収を遮断しません。ゲーム時間で消え、従来の手動ポーズ／ショップ／フォーカス喪失では時計が止まります。BGMは通常フェーズ間では継続し、ボス突入／撃破は既存音声管理で切り替えます。

## この拡張の変更ファイル

- `src/features/modes.js`（新規）：モード別武器設定、追加装備初期化。
- `src/features/endless.js`（新規）：進行、敵テーブル、倍率、独立記録。
- `src/features/extraWeapons.js`：利用条件の共通化、クラシック未選択状態への対応。
- `src/features/extraEnemies.js`：エンドレス小型機、インスタンスごとの攻撃頻度。
- `src/features/challenge.js`：敵出現処理を差し替え可能にし、エンドレスと戦闘更新を共有。
- `src/main.js`：選択メニュー、全モード装備、エンドレス更新／結果／保存／音声接続。
- `src/rendering/endless.js`（新規）：非停止フェーズ表示。
- `src/rendering/renderer.js`、`challenge.js`、`hud.js`、`particles.js`：表示統合、全モード装備描画、常設PHASE、エンドレス警告の重複防止。
- `tests/endless.test.js`（新規）、`game.test.js`、`challenge.test.js`、`regression.test.js`：拡張・本番統合の検証と新しいimportへの対応。
- `README.md`、本報告、`docs/endless-check.html`、`docs/screenshots/endless-phase2.png`：説明、ブラウザ検証用フィクスチャ、撮影結果。

`src/config.js`、`src/model.js`、従来のセーブキー／構造は変更していません。エンドレス記録は `star-credit-endless-v1` の `{version:1,score,phase}` に最高値を別保存し、保存不能時はメモリ上でプレイを継続します。

## 検証結果

`node --test`：42件成功、失敗／スキップ0。拡張前35件から7件追加しました。「追加装備はチャレンジ限定」の旧期待値だけを今回の要求に合わせて変更し、他の既存テストは維持しました。

全モードの追加装備性能一致、境界中の攻撃／被弾／回収、既存物体・強化・装備保持、単体ボス、HP0優先、ボス撃破後の継続、PHASE 102描画、倍率上限、旧／破損／保存禁止データを検証。10万回の更新（5000ゲーム秒、ボスはテストで撃破）で三桁フェーズに到達し、敵・弾・回収物の合計が500未満を維持しました。実機FPS測定ではありません。

追加装備OFFのクラシックは旧版と同じ乱数・入力で1200フレームの状態が完全一致。180秒ボス、90秒チャレンジ、強化、回収、音声、停止／再開始の回帰テストも成功しました。

ブラウザで本番タイトルからENDLESSを開始し、初期表示とSpace切替を確認。別の検証ページで本番update/render/frameを44.9秒から実行し、PHASE 02と中央帯が出ている間に25クレジット回収、発射弾・残存敵弾を確認。その後01:03まで更新、スコア165／残高80への増加と右移動を確認しました。幅約423pxでも自機の被弾位置とHUDが見えています。ブラウザ警告・エラーログは0件でした。

## 未確認事項

高フェーズまでの実機通しプレイ、端末別FPS／負荷、聴感上のBGM切替、実ブラウザ再起動による保存復元は未確認です（保存復元・失敗耐性と音声状態は自動テスト済み）。難易度倍率は暫定値。フェーズ表示時間／強度の個別設定は望ましい項目ですが、今回の必須機能としては追加していません。

作業ブランチは `feature/endless`。以前のフェーズ実装の未コミット差分を保持し、Pushは行っていません。
