# Phase 3 実装結果

Phase 2は実装せず、ユーザー指定によりPhase 3を実施。開始時点のPhase 1未コミット変更は維持。戦闘定数・モデル・描画ロジック・既存保存キーは変更なし。

## 変更ファイル

- `src/audio/soundCatalog.js`：オリジナル仮BGM5場面、効果音の合成パラメータ。
- `src/audio/audioManager.js`：ユーザー操作後のContext有効化、独立した音量バス、発音上限、ビーム単一継続音、BGM切替、150msボスクロスフェード、停止・再開、例外分離。
- `src/main.js`：状態・発射・被弾・撃破・回収・購入・メニューの音声イベント。音量UIと追加設定保存。
- `src/style.css`：音量項目追加時に短い画面でもメニュー上端へスクロール可能にする調整。
- `tests/audio.test.js`：音声テスト7件。
- `tests/game.test.js`、`tests/regression.test.js`：VMへの音声モジュール注入のみ。既存検証を維持。
- `docs/audio-check.html`：実AudioContext確認用独立ページ。保存データは変更しない。
- `README.md`、本書：操作・保存互換・確認結果。

## 確認結果

同梱Node v24.19.0による `node --test`：既存13件＋音声7件、20件全合格。非対応、Context生成失敗、resume拒否でも無音で続行。二重再生防止、個別音量・ミュート、発音上限、終了ジングルの非表示復帰後の再発音防止を検証。既存の1,200フレーム戦闘状態比較も一致。

実ブラウザでミュートON/OFF、出撃、Spaceビーム切替、ショップ、ポーズと設定表示を確認。音声確認ページで `contextState: running`、戦闘→ボス切替、停止時 `track: null / voices: 0`、再開後の発音を確認。ブラウザエラーログなし。進行中のユーザープレイは別タブで保持し、確認は新規タブで実施。

## 音源出典と制約

曲と効果音はこのプロジェクト向けに新規作成した合成パターン。外部録音・ゲーム曲・サンプルは不使用。初期仮音源であり、完成BGMと区別する。外部素材ロードは行わないため、そのロード失敗経路は今回対象外。音声APIの失敗経路は検証済み。

実聴による音質・音量バランス、実ボス到達時の音声、長時間連続プレイ、OS出力デバイス変更・各ブラウザ差は未確認。画面振動・CRT・新武器・新敵等は追加していない。
