# Phase 5 スマホ操作改善

## 変更内容

粗いポインターを持つ端末では相対ドラッグを標準にしました。機体から離れた画面上の場所に指を置いても自機は飛ばず、指の移動量だけを480×800の論理座標へ変換します。最大移動速度280と境界は維持。端でドラッグを続けた後も逆方向へすぐ戻せます。タイトル／ポーズの操作設定に「タッチ移動方式」を追加し、従来の絶対位置方式も選べます。この設定はセッション中のみで、再読込すると相対方式へ戻ります。

スマホの操作ボタンは固定2段です。上段＝武器・追加装備・チャージ、下段＝強化・停止。チャージ装備でない時は保持ボタンを隠します。44pxの高さ、8pxの列間隔を確保。移動指とチャージ指の所有者を別々に管理します。

小型画面向けCSSは幅600px以下かつ粗いポインター環境だけに適用。100dvh（未対応時100vh）とsafe-areaを使い、見出し・HUD・104pxの操作領域を先に確保し、残りへ戦闘Canvasを収めます。Canvas内部解像度と比率は維持し、必要な余白はobject-fit:containで表示します。メニューは内部でスクロール可能です。

戦闘中のCanvasと操作領域にtouch-action:none、選択／長押しメニュー抑制、overscroll抑制を適用。非passiveのtouchmoveとSafari gesturestart／gesturechangeを戦闘中だけ抑制します。フォームは16px文字で入力時の自動拡大を抑えます。全ページのuser-scalable=noは指定せず、メニューの閲覧性は維持します。OSのアクセシビリティ拡大や画面端のシステムジェスチャーまで無効化するものではありません。

通常ボタンは所有する指をボタン内で離した場合だけ実行。別指・外側への指離し・キャンセルでは操作せず、合成clickの二重実行を防ぐ処理を追加しました。回転・ポーズ・フォーカス喪失ではタッチ入力を解除。スマホの途中チャージは破棄し、復帰時の誤発射を防ぎます。PCキーボード／パッドの割当、移動、保持、ポーズ処理は維持しました。

## 実施した検証

`node --test`：63件成功、失敗／スキップ0。従来56件のテストを削除・無効化・期待値変更せず維持し、7件追加しました。

相対開始時の位置保持、拡縮座標変換、端での反転、指所有権、移動指／チャージ指を異なる順番で離す同時タッチ、キャンセル、回転・ポーズ後の誤発射防止、ボタン外の指離し、別指、二重解放を検証。従来のキーボードとパッド、本番3モード、クラシック1200フレーム比較も成功しました。

ブラウザの320×480表示で模擬ページを確認。CanvasのCSS領域は306×277.5px、操作ボタンは約92.7×44px、最下部は469px。document scrollHeightは480pxで、全戦闘画面と主要5ボタンが同時表示されました。論理画面のアスペクト比を保つため左右に余白が生じます。デスクトップの粗いポインター判定をフィクスチャで置き換えた表示確認であり、iPhone／Safari実機の操作検証ではありません。表示サイズの上書きは確認後解除しました。

## 未確認とSafari実機での検証手順

実iPhone／Safari、実タッチの同時イベント順、アドレスバー伸縮、ノッチ／ホームインジケーター、長押し／ピンチ／連打の抑制効果は未確認です。完了扱いにしていません。

1. 同じネットワークのiPhoneから開発サーバーのLANアドレスを開く（サーバーの起動表示にあるURL）。小型iPhone SE相当を優先し、Safariのアドレスバーを表示したまま縦向きで開始する。戦闘の上下端と全ボタン、ホームインジケーターとの重なりを確認。
2. 「相対ドラッグ」で自機から離れた場所に左指を置く。開始時に自機が動かず、上下左右・斜めに指の移動量に従うことを確認。画面端で押し続けた後、逆方向へすぐ動くか確認。従来方式への切替も確認。
3. Qでチャージ装備を選ぶ。左指で移動しながら右指で保持ボタンを1.2秒押し、右指だけ離す。1発だけ発射し、左指による移動が続くことを確認。次に左指を先に離し、チャージだけが継続することを確認。
4. ボタン上で押してから外側へ移動して離す、別指を追加、連打、保持中の長押しを試す。勝手な武器切替・ショップ表示・二重発射・選択メニューが出ないことを確認。
5. 戦闘中に縦ドラッグ・2指ピンチ・ダブルタップ・画面端スワイプを試す。ページのスクロール／ズームや入力残留を確認。メニューでは内部スクロール・キー設定欄の閲覧が可能であることも確認。
6. 移動と溜めの途中で停止、アプリ切替、画面回転を行う。戦闘が停止し、明示再開後に指が残らず誤発射しないことを確認。Safariのアドレスバー表示／非表示、横向きから縦向きへの復帰も確認。
7. iOSバージョン・機種・縦横・表示領域・症状を記録し、PCのキーボードと物理パッドでも従来の操作を再確認する。
