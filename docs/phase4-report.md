# Phase 4 実装結果

現行モードを維持し、タイトルで明示選択する独立したチャレンジを追加。既存の未コミット変更は保持。Phase 2の改修とPhase 5以降は実施していない。

## 変更ファイル

- `src/features/extraWeapons.js`：拡散・貫通・追尾・チャージの追加スロット、寿命・命中済みID・追尾対象管理。
- `src/features/extraEnemies.js`：4新敵、チャレンジ進行設定、3段階新ボス。
- `src/features/challenge.js`：専用モードの戦闘更新。通常モードでは呼ばれない。
- `src/main.js`：モード選択・専用更新分岐・Q入力・装備表示・モードを保持するリトライ・別ハイスコア保存。
- `src/rendering/challenge.js`：追加弾、シールド、新敵名称、ボス攻撃方向予告、装備／チャージ表示。
- `src/rendering/renderer.js`、`hud.js`：専用描画の呼出し、新敵の最大HPとボス段階。通常モードの表示値は維持。
- `tests/challenge.test.js`：追加機能8テスト。
- `tests/game.test.js`：既存内容を維持し、本番チャレンジ分岐の統合テスト1件追加。
- `tests/regression.test.js`：VMへの追加モジュール注入のみ。旧版との比較を維持。
- `docs/comparison.html`：新ボス固定描画確認用シーン追加。
- `README.md`、本書、`docs/screenshots/phase4-*.jpg`：操作・確認記録。

## 初期バランス（チャレンジ限定の提案値）

通常戦90秒、出現間隔1秒。0–30秒は偵察／シールド、30–60秒はリーダーも追加、60–90秒は砲台も追加。該当種類から等確率で出現し、残存通常敵の退場後に新ボス。

| 装備 | 初期性能 |
| --- | --- |
| 拡散弾 | 3方向、各威力1、0.6秒間隔、速度480 |
| 貫通弾 | 威力2、3敵まで、同一敵1回、0.8秒間隔、速度540 |
| 追尾ミサイル | 威力4、1秒間隔、速度260、対象消滅時に再探索 |
| チャージ | F保持、最大1.2秒で威力12、解放時1発、速度440 |

追加弾の寿命は3秒。追加装備は最初から使用でき、既存の自動弾／ビームに併用。装備OFFも選択可能。追加装備の強化や解放条件は今回導入していない。

偵察機HP3／報酬15、シールド機HP8＋シールド4／35、リーダーHP10／40、砲台機HP18／60。新ボスHP240／報酬300、HP70%・35%で第2・第3段階。予告0.7秒、3→5→7方向、攻撃後1.6→1.4→1.2秒の休止。狙いは予告開始時に固定し、予告後のプレイヤー移動を追い直さない。

## 保護した仕様

`src/config.js` と `src/model.js` は変更なし。通常ステージの180秒・敵配分・4既存敵・武器性能・Space切替・5強化価格・当たり判定・回収・リトライ初期化を維持。チャレンジ専用スコアは別保存キーに分離。既存保存構造を変更しない。

## 確認結果

同梱Nodeによる `node --test`：既存20件＋新規9件、29件合格。1,200フレームの通常モードの旧版比較が一致。追加武器4種、貫通の重複禁止・寿命、再追尾、チャージ解放、シールド吸収、ボス予告・HP段階、退場待ち、HP0優先、本番の停止・クリア自動回収・再開始・通常モード復帰を検証。

ブラウザでチャレンジ開始、Q装備切替、Spaceビーム、F保持／解放キー入力、ショップ表示を確認。ゲームオーバー結果で専用ハイスコアが表示され、通常ハイスコアが維持されることを確認。新ボスの予告・第3段階は固定状態フィクスチャで目視確認。エラーログなし。

## 未確認事項

実プレイによる90秒突破から新ボス撃破までの通し確認、F操作時の威力と手触り、全追加装備の難易度・報酬バランス、予告線と実弾幕の実プレイでの一致、連続リトライ・保存禁止状態の実ブラウザ確認は未実施。新敵は既存のオリジナルスプライトを再利用し、名前とシールド表示で識別する初期アート。外部素材は不使用。
