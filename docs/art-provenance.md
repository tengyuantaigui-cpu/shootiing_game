# Phase 1 アートの出典

`src/rendering/sprites.js` の自機・小型機・中型機・重装機・ボス・敵弾・クレジットは、このプロジェクト向けに新規作成したオリジナルのピクセルパターンです。星空・自機弾・噴射炎もコードで作成しています。外部画像・既存ゲーム素材・フォント・音源は利用していません。

これらは初期アートです。完成素材とは区別し、今後差し替える場合も描画サイズと当たり判定を独立させます。追加の外部素材ライセンスへの依存はありません。プロジェクト全体の配布ライセンスは未設定です。

## Phase 5 スキン

MINT・GOLD・VIOLETは既存のオリジナル自機ピクセルパターンの主色をコードで変更したものです。新しい外部画像・フォント・音源は使っていません。パターン寸法と白い被弾点は同一です。
