# Phase 6 品質改善・リリース準備（2026-10-11）

## 判定

コード上の品質改善・自動QA・PCブラウザ／スマホ相当サイズでの確認を実施。iPhone実機、公開HTTPS環境、ホーム画面からの起動・更新・保存は未確認なので、リリース完了とは扱わない。既存JavaScript／Canvas／Web Audio／Node標準ランナーを維持し、新規依存・フレームワークは導入していない。

## 今回の修正と重要度

|重要度|問題|対応・状態|
|---|---|---|
|中|毎フレームHUDのHTML全体を交換|表示値が変わった時だけ更新。回帰テスト追加|
|中|長いメニューの上端が中央揃えで隠れる可能性|短いパネルはauto marginで中央、長いパネルは先頭からスクロール可能に修正|
|中|公開先で同名ファイルが古いまま残る可能性|開発サーバーと公開用 `_headers` に全資産の `Cache-Control: no-cache`。公開先適用確認は残る|
|低|PCのキー再割当成功／拒否時にSEがない|既存audioManagerにmove／deniedを各1回委譲|
|要実機確認|iOSの音声・ノッチ・復帰・入力遅延|チェックリストに残す|
|要プレイ確認|低確率武器の戦闘内育成が遅い|分析のみ。値は変更していない|

今回の点検範囲で再現した重大フリーズ・操作不能はない。ただし短時間の確認であり、全機種・長時間・全ボスの実プレイ保証ではない。

## 音響・入力

タイトル・通常戦闘・ボス・後半エンドレスの4曲を維持。装備／強化は50%、設定は100%、ポーズは25%で継続し、リザルトはタイトルBGM。OFF・ミュート優先、背景で中断、復帰のユーザー操作で再開。初期自動再生が保留でも最初の操作でresumeを再試行する。iOSで操作前の自動再生は保証しない。

ブラウザの検証用ページで実M4Aのtitle/battleの読み込み・再生状態を確認。boss/endless、読み込み失敗時の合成曲、重複抑止、音量・保存は自動テストを含む既存QAで確認。スピーカーでの実聴は未確認。

移動指とCHARGE指は別所有者。メニュー遷移、ポーズ、キャンセル、フォーカス喪失で入力を解除し誤発射を防ぐ既存テストを維持。PCキーボード・ゲームパッドの割当や移動ロジックは変更していない。

## バランス検証

追加武器はbattle inventoryで取得までロック、開始・終了・タイトル帰還でパルス弾Lv.1へ戻る。戦闘所持・育成を永続保存せず、旧v2/v3セーブは保持して隔離する既存テストが成功。

固定シード6、10万撃破の抽選：4921ドロップ（4.921%）。bullet1079、beam1057、spread1064、piercing700、missile692、charge329。設定5%、重み3/3/3/2/2/1との整合を回帰テストで確認。コイン100%と武器の独立抽選・二重付与防止は既存テストで確認。

初期設定ではチャージの1撃破あたり確率は約0.357%、初入手までの平均は280撃破。Lv.2まで初回＋重複2回で平均840撃破、Lv.5まで計15回で平均4200撃破。回収失敗を無視した期待値であり、1戦の育成速度には実プレイ検証が必要。今回の指示に従い確率・成長・敵HPを変更しない。

MAGNETは40→80→120→180px、価格50/100/200、吸引速度360px/秒。コインと武器共通、確率に影響しない。小型敵報酬10なら初回購入は5回回収相当。クラシックの初期パルス弾理論4ダメージ/秒、ボスHP180は45秒の連続命中相当。回避・命中率・ドロップ・購入による実難易度は自動計算だけでは判定しない。

## PWA・キャッシュ・保存

manifestのstandalone／portrait、iPhoneメタタグ、アイコン寸法、四辺セーフエリア、旧セーブ互換を自動検証。公開ビルド成功。

Service Workerはなく、オフライン用キャッシュを追加していない。初回／完全オフライン起動は保証せず、表示中のゲームは読み込み済みコードで動く。音源取得失敗時は合成BGMへフォールバックする。実際の機内モード検証は未確認。

`_headers` を解釈するCloudflare Pages／Netlify等では全資産を再検証。ほかのホストでは同じレスポンスヘッダーを設定する必要がある。HTTPキャッシュを再検証する方針で、保存領域の削除・自動更新リロード・プレイ中断は行わない。既に開いたタブは次回リロードまで現在のコードを使う。稼働中の開発サーバーは再起動まで新ヘッダーが反映されない。公開先の実ヘッダーと更新、CDNキャッシュ、PWAインストールは未確認。
