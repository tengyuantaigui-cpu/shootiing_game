# Phase 0 — ベースライン

開始時点ではGitリポジトリなし。既存ファイルは削除・破棄せず、全ファイルを初期履歴へ保存する。戦闘比較用に元のmain/config/modelを `docs/baseline/` に保存。

既存テスト：8件合格（Node v24.19.0、`node --test`）。この環境ではnpmがPATHにないため、同じテストランナーを同梱Nodeで直接実行。

## 今回の差分と範囲

| 要素 | ベースライン | Phase 1 |
| --- | --- | --- |
| 描画 | main.js内に集約 | rendering内へ分割、状態は読み取りのみ |
| 自機・4敵タイプ | 多角形 | オリジナルのピクセルパターン |
| 星空 | 一層 | 遠・中・近の3層 |
| 弾・回収物 | 矩形・円・菱形 | ピクセル表示 |
| HUD・メニュー・既存エフェクト | 現行表示 | 維持（Phase 2未着手） |
| 音声・追加機能 | 未実装 | 変更なし（Phase 3以降未着手） |
