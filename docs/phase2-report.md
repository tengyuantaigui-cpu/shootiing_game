# Phase 2 実装結果

Phase 3・4までの実装を保持し、後からPhase 2を追加。戦闘定数・モデル・既存の保存形式は変更なし。Phase 5以降は未着手。

## 変更ファイル

- `src/rendering/hud.js`：HP・残高・スコア・武器名／性能・時間・モード・WAVE/BOSSを表示するレトロHUD。
- `src/rendering/particles.js`：独立した演出時計、短命ピクセル粒子、回収／購入通知、2秒のボス出現警告、振動・フラッシュ・CRT設定、追加保存キー。
- `src/rendering/renderer.js`：演出描画と設定反映。ゲーム状態への書き込みは行わない。
- `src/main.js`：イベントの演出通知、戦闘中のみ演出更新、開始時リセット、タイトル／ポーズ設定UIと保存。
- `src/features/challenge.js`：チャレンジのヒット・回収を同じ演出へ通知。
- `src/style.css`：HUDとメニューのアーケード風表示、設定操作と狭い表示への対応。
- `tests/visuals.test.js`：HUD値・ボスHP・粒子上限／寿命・設定・描画の非更新性。
- `tests/game.test.js`：本番のショップ／ポーズ中の演出停止確認。既存検証は維持。
- `tests/regression.test.js`：VMへの演出モジュール注入のみ。
- `docs/comparison.html`：固定状態の演出比較シーン。
- `README.md`、本書、比較画像：操作・確認記録。

## 保護と設定

従来のリング効果を残し、短命粒子と通知を追加。粒子100個、ヒット粒子約18個、通知20件の上限。乱数を使用せず、ゲーム用乱数列や当たり判定に影響させない。演出時計は戦闘中のみ更新し、ショップ・ポーズ・フォーカス喪失では停止。

粒子は初期「控えめ」（強度0.35）、多め0.7／OFF0。振動は被弾時の最大2px、被弾フラッシュは弱い透過色、CRTは走査線のみ。振動・フラッシュ・CRTは初期OFF。設定保存は `star-credit-visual-v1` とし、破損・保存不可でも続行。粒子OFFでも既存リング・文字通知・重要なボス警告は表示する。

## 検証

同梱Nodeの `node --test`：既存29件＋Phase 2の6件、計35件合格。旧版との1,200フレーム戦闘状態比較が一致。HP・残高・スコア・武器性能・WAVE、通常ボスHP180／追加ボス最大HP240のバー幅、粒子の寿命・上限・リセットを確認。描画のみでは演出時計が進まず、本番ショップ・ポーズ中も粒子・通知・警告が停止。

実ブラウザで設定変更と再読込による復元（粒子多め／CRT ON）、元の初期設定への復帰を確認。HUD、警告、粒子・回収文字通知は固定状態の比較ページで目視確認。
