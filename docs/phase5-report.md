# Phase 5 実装報告

## 実装内容

Phase 5の7項目（図鑑、実績、スキン、ラン記録、キー設定、ゲームパッド、スマホ操作）を実装しました。Phase 6の端末別品質確認・最適化には着手していません。

タイトル／ポーズから「図鑑・実績・スキン・ラン記録」を開けます。ポーズから開いた場合は、戻ってもポーズを維持します。

- 図鑑：既存4タイプ＋追加5タイプの遭遇／撃破数。未遭遇の敵は能力を伏せ、遭遇後に初期HP・速度・報酬を表示。エンドレス小型機は既存小型機に合算し、倍率を図鑑の初期値に混ぜません。
- 実績：初撃破、初クリア、ノーダメージクリア、いずれかの武器を最大強化、モード別ハイスコア更新。ノーダメージはラン中の実際の被弾イベントと終了HP3を確認します。途中帰還はクリア扱いにしません。
- スキン：MINT（標準）、GOLD（初撃破）、VIOLET（初クリア）。既存のオリジナル自機パターンの主色だけを変更。座標・描画寸法・被弾点・戦闘性能は同一です。
- ラン記録：終了時のモード、スコア、撃破数、累計回収、クリア状況、時間、エンドレス到達フェーズ、終了時刻。最新50件を保存。途中でタイトルへ戻ったランは記録しません。
- キー設定：タイトル／ポーズの折りたたみ「操作設定」から、キー欄にフォーカスして押下したキーを登録。移動は2割当、他操作は1割当。全戦闘操作の重複を拒否し、破損データは標準へ戻します。Tab／Enterとメニューの上下矢印は固定。画面の操作案内も更新します。
- ゲームパッド：Gamepad APIのstandardマッピング。左スティック／十字キー移動、下ボタン＝武器／メニュー決定、右＝追加装備／メニューから戻る、左を保持＝チャージ、上＝強化、START＝停止／再開。メニューは十字キー上下で選択。デッドゾーン0.2、連続押下の二重切替を防止。ポーズ後は一旦ニュートラルに戻す必要があります。切断は自動ポーズ。複数接続時は最初のstandardパッドを使用します。
- スマホ操作：戦闘Canvas上のタッチ／ペンのドラッグで移動。見た目の余白を補正して480×800座標に変換し、最大速度280・既存境界を維持。武器・追加装備・ショップ・ポーズは既存ボタン、チャージ選択時は保持ボタンを追加。ドラッグ終了／キャンセル／フォーカス喪失で入力を解除し、粗いポインター環境では操作ボタンを大きくします。仮想スティックは追加していません。

## 互換性・保存

メタ進行は `star-credit-meta-v1`、キー設定は `star-credit-input-v1` にversion 1で別保存。従来のハイスコア・音量・チャレンジ・エンドレス・演出の保存キーと構造は維持しました。保存不可でもメモリ上で続行します。

ラン本体にメタ進行やスキン設定を追加せず、リトライは従来の `newRun()` を使います。スキン・図鑑・実績・記録・設定だけを引き継ぎます。永久強化、価格変更、敵や武器の数値変更はありません。図鑑の二重登録を防ぐ個体管理にはWeakSetを使い、エンドレスの過去の全敵を保持しません。

音声は既存管理を使用し、タイトルからの収集閲覧ではタイトルBGM、ポーズからでは無音のポーズを維持します。初回の音声有効化にはブラウザが認めるクリック／キー操作が必要です。パッドだけで起動した場合の音声許可はブラウザ依存です。
