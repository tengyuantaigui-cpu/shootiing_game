# STAR CREDIT

`shooting_game_spec.md` の段階1〜4を実装した、PC・スマホブラウザ用の縦スクロールシューティングです。HTML CanvasとJavaScript ES Modulesで構成し、依存ライブラリはありません。

## 起動

Node.js 18以上で `npm run dev` を実行し、http://localhost:5173 を開いてください。`node server.js` でも起動できます。ファイルを直接開くのではなくHTTPサーバーを利用してください。

## 操作

- 矢印キー / WASD：移動（攻撃は自動）
- Space：その戦闘で取得済みの弾とビームを切替
- Q：その戦闘で取得済みの追加攻撃を選択
- F：チャージを保持して離すと発射（取得・装備後）
- U：強化画面を開閉
- Esc：一時停止 / 再開
- メニュー：クリック、Tab / Enter、上下キー / Enter

◇を回収した時だけ残高が増加します。弾数の最初の強化は50クレジットです。180秒後、通常敵が退場してからボスが登場します。機体中心の白い点が被弾範囲です。

## 構成と調整

- `src/config.js`：敵、出現、武器性能、強化費用
- `src/model.js`：プレイ状態、回収、購入、保存復元
- `src/main.js`：時間基準の戦闘更新、描画、入力、メニュー
- `src/style.css`：画面比率を保つ表示とUI

アーケード化のPhase 0・1では、`src/rendering/` に描画を抽出し、自機・敵・弾・回収物をオリジナルのドット絵に、星空を3層に変更しました。HUD・メニュー・戦闘計算・保存形式は維持しています。Phase 2のHUD・エフェクト改修と演出設定を実装しました。Phase 4で追加装備・新敵・新ボスを実装し、その拡張で追加装備の全モード対応とエンドレスを追加しました。Phase 5の収集・操作拡張も実装しました。Phase 6は未着手です。詳細な比較・確認結果は `docs/regression-checklist.md`、素材の出典は `docs/art-provenance.md` を参照してください。

強化・一時停止では戦闘更新を停止します。フォーカス喪失でも自動停止し、明示的な再開を待ちます。リトライはすべてのプレイ状態を作り直します。保存はバージョン付きlocalStorageでハイスコア・設定・収集進行を扱い、失敗時も続行できます。

## Phase 4：チャレンジ

タイトルの「チャレンジ：追加装備と新敵」から開始します。通常の「出撃する」はこれまでの180秒ステージです。

チャレンジは90秒後、通常敵が退場してから新ボスが登場します。Spaceは従来どおり弾／ビーム。攻撃方法は1つを装備し、Qで所持済みの追加攻撃を切り替えます。チャージはFを押して最大1.2秒溜め、離して発射します。他の追加装備は自動発射です。

偵察機・シールド機・編隊リーダー・砲台機が登場し、新ボスはHP70%と35%で段階が変わります。攻撃前の予告線は発射予定方向を表し、ボスは予告後に攻撃し、攻撃間に休止を挟みます。既存5強化は同じ価格・性能で利用できますが、追加装備の性能は独立しています。

リトライは同じモードで初期化。タイトルから通常ステージへ戻れます。ハイスコアは別キー `star-credit-challenge-v1` に保存し、通常ステージの記録に混ぜません。追加装備・敵の数値は `src/features/extraWeapons.js` と `src/features/extraEnemies.js` で調整できます。詳細は `docs/phase4-report.md` を参照してください。

「設定」で粒子の強度（OFF／控えめ／多め）、画面振動、被弾フラッシュ、CRT走査線を変更できます。初期値は粒子「控えめ」、振動・フラッシュ・CRTはOFF。設定は別キー `star-credit-visual-v1` に保存し、従来の保存形式を維持します。粒子OFFでも既存のリング効果や回収・購入通知は残ります。

HUDをアーケード風に変更し、撃破・ヒット・被弾の短命粒子、回収／購入通知、ボス出現時の2秒警告を追加しました。これらは戦闘時間と別管理し、ショップ・ポーズ中は停止します。詳細は `docs/phase2-report.md` を参照してください。

## PWA：iPhoneのホーム画面から起動

`manifest.webmanifest` の `standalone` とiPhone用メタタグを追加しました。ホーム画面用の180px PNG、Webアプリ用の192px／512px PNGは既存の自機ドット絵から生成しています。再生成は `node tools/generate-icons.mjs`。スマホは既存の相対ドラッグ・2段ボタン・`100dvh`・四辺のセーフエリア対応を使用します。縦向きを指定していますが、iOSで画面固定を保証するものではありません。縦画面での使用を推奨します。PCのキーボード／ゲームパッド、全モード、保存キー・保存形式は変更していません。

### HTTPSで公開する

```sh
npm run build
npm test
```

静的ホスティングの公開ディレクトリを `dist/` に設定し、有効な証明書のあるHTTPSドメインのルート `/` に配置してください。依存パッケージのインストールは不要です。NodeがPATHにない環境では、上記のNode絶対パスで `tools/prepare-publication.mjs` と `--test` を実行できます。

公開物は `index.html`・`manifest.webmanifest`・`src/` だけです。リポジトリ全体や開発用 `server.js` を公開する必要はありません。サブディレクトリ公開は現状の絶対パスとmanifestのscopeに対応していません。公開先で `.webmanifest` は `application/manifest+json`、`.png` は `image/png`、`.js` はJavaScriptのContent-Typeで返してください。すべて同じHTTPSサイトから読み込み、HTML／manifestは再検証されるキャッシュ設定を推奨します。

`npm run dev` は引き続きHTTPの開発確認用です。サーバーを再起動するとmanifest／PNGのContent-Type変更が反映されます。HTTPS公開・証明書・実際の公開URLはまだ未確認です。

### iPhoneに追加する

1. iPhoneのSafariで公開先のHTTPS URLを開きます。
2. 共有メニューから「ホーム画面に追加」を選びます。見つからない場合は共有メニューのアクション編集を確認します。

4. ホーム画面のアイコンをタップして起動し、Safariのアドレスバーが表示されないことを確認します。

メニュー表示はiOSのバージョンにより異なります。[Appleの追加手順](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)も参照してください。

保存処理は維持していますが、HTTPからHTTPSへの変更や別ドメインは別の保存領域になります。また、SafariのlocalStorageがホーム画面アプリへ引き継がれることは保証できません。[WebKitの説明](https://webkit.org/blog/14787/webkit-features-in-safari-17-2/)ではlocalStorageはコピー対象外です。保存の移行機能は今回追加していません。ホーム画面アプリ内でプレイして閉じ、同じアイコンから再起動して記録・設定が復元されることを実機で確認してください。

Service Worker・オフライン機能は追加していません。起動には通信が必要です。Capacitor／Xcode、App Store公開、課金、ログインも対象外です。既存63件とPWA回帰4件の計67件が成功しました。変更ファイル・未確認事項・実機検証手順は [PWA実装報告](docs/pwa-report.md)を参照してください。


## ドロップ・武器育成・MAGNET

敵の撃破では従来どおりコインを必ず出し、別枠で初期5%の武器アイテム抽選を行います。どちらもフィールド回収で獲得します。武器のドロップでコインが減ることはありません。ボスクリア時の残アイテム自動回収は維持しています。

「装備」メニューに攻撃方法の管理を統合しました。スマホはカードをタップ、PCはマウスまたは上下矢印／Tab・Enterで選択します。攻撃方法は1つだけ装備し、弾とビームはSpace、所有している追加攻撃はQでも選択できます。初期装備はパルス弾だけです。ビーム・拡散弾を含む残り5種類は、その戦闘で拾うまで装備できません。初回入手はLv.1、重複2・3・4・5個で順にLv.2〜5へ育成します。最大Lvでは重複を消費し、追加コインや進捗は付与しません。

武器Lvの威力倍率は1／1.15／1.35／1.6／2。従来のショップ強化とは独立し、弾・ビームはショップ威力に、追加装備は基本威力に掛かります。発射間隔・移動速度・当たり判定は変更していません。入手時のNEW・LEVEL UP通知と、武器名・レアリティ・Lv・育成進捗の一覧を表示します。

ショップの「MAGNET / 吸引範囲」は40→80→120→180px、価格50→100→200コイン。吸引速度の初期設定は全段階360px/秒です。範囲外の落下速度90px/秒と、接触回収距離16pxは維持しています。コイン・武器に同じ吸引処理を使います。MAGNETはランごとの強化で、リトライ時に40pxへ戻り、ドロップ率は変えません。

調整場所：`src/features/weaponCatalog.js` の `WEAPON_DROPS`（基本率・敵別率・敵別候補）、`WEAPON_CATALOG`（重み・レアリティ・上限・重複数・威力・最大Lv時の処理）、`src/config.js` の `UPGRADES.magnet` と `CONFIG.magnetSpeeds`（範囲・費用・速度）。敵別設定キーは `classic-0`〜`classic-3`、`recon`／`shield`／`leader`／`turret`／`boss`／`small`。敵個体の `weaponDropRate` でも率を上書きできます。

攻撃方法の所有・Lv・進捗・装備は戦闘内だけで保持し、永続保存しません。戦闘終了・タイトル復帰・再出撃でパルス弾Lv.1に戻ります。エンドレスのフェーズ切替では保持します。旧v2/v3の武器保存データは削除せず、新しい戦闘には読み込みません。スコア・音響・操作・収集進行の保存方式は維持しています。
